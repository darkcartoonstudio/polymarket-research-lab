# Contributing

Thank you for improving this research resource. Contributions should prioritize clarity, reproducibility, and accurate uncertainty.

## Good contributions

- Fix an incorrect technical statement with a current source.
- Add a small, reproducible test or method note.
- Document data requirements, limitations, or failure cases.
- Add an out-of-sample or walk-forward evaluation with explicit denominators and cost assumptions.
- Improve the SVG diagrams or French/English documentation.

## Required for a new result

Include the hypothesis, dataset/version, time range, sampling and exclusion rules, feature timing, train/validation/test split, fee/execution assumptions, sample count, uncertainty, and a way to reproduce the calculation. State whether the outcome is exploratory, backtested, out-of-sample, paper-observed, or live-observed.

## Do not contribute

- API keys, private keys, tokens, wallet/account identifiers, `.env` files, raw account logs, private databases, or executable archives.
- A performance claim without the underlying method and a clear denominator.
- Strategy instructions that imply a result is guaranteed or risk-free.

Open an issue first for large additions. Small corrections can be submitted directly as a pull request.
